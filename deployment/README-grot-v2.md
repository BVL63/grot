# Отдельный сайт ГРОТ 2.0 — инструкция

Цель: независимый публичный сайт `https://bvl63.github.io/grot-v2/` без изменения `BVL63/grot` / `main`.

## Первый запуск

1. В GitHub создать **публичный пустой репозиторий** `BVL63/grot-v2` с файлом README (без импорта исходников).
2. Скопировать файл `deployment/grot-v2-pages.yml` из ветки `develop/v2` основного репозитория в **новый** репозиторий по пути `.github/workflows/pages.yml`. Сохранить в ветку `main` нового репозитория.
3. В новом репозитории открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Открыть **Actions → GROT 2.0 — independent GitHub Pages → Run workflow**.
5. Если тесты и сборка пройдут, адрес: `https://bvl63.github.io/grot-v2/`.

## Защита рабочего сайта

Workflow работает в **новом репозитории** и лишь читает `BVL63/grot@develop/v2`. Для `BVL63/grot@main` нет ни одного шага записи. Для сайта на Pages публикация производится только в новом репозитории.

Персональные данные работников и присланная резервная копия в репозиторий не добавляются. Пользователь загружает JSON локально в браузере для проверки.

## Ограничения

В публичном сайте будет доступен демонстрационный экран без аутентификации. Это **не рабочая база**. Изменения не хранятся на сервере и теряются при перезагрузке, если не скачать JSON. Не следует считать пробный режим безопасным для хранения конфиденциальной кадровой информации.

После первоначального запуска ежедневная проверка запланирована на 03:17 UTC; при сбое тестов публикация не произойдёт. При необходимости ручной запуск делается через Actions.
