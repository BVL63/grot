# ГРОТ 2.0 — единый интерфейс годов

Рабочая ветка: `develop/v2`. Версия `main` и архивная ветка не изменяются.

## Принципы
1. Таблица графика, карточка сотрудника, редактор периодов, печать, группы и контроль конфликтов используют одни и те же компоненты для любого года.
2. Выбор года меняет данные, а не форму.
3. План и факт — разные поля одного отпуска. Изменение факта не перезаписывает план.
4. Графики каждого года изолированы. Данные прошлого года не подменяются копией следующего.
5. При создании года копируется только актуальный состав и атрибуты сотрудников; периоды не копируются автоматически.
6. Годы 2025/2026/2027, включая исходные исторические данные, должны проходить через безопасный адаптер. Ни одна миграция не удаляет старые ключи localStorage до проверенной резервной копии.
7. Состояния графика: draft, submitted, approved, archived. Архивность не следует автоматически выводить только из числа года. Исправление утверждённых/исторических данных — отдельное действие с причиной и записью в журнал.
8. Администратор может исправлять разрешённые данные, но не утверждать. Утверждение только руководителем в локальной сети.
9. План текущего года может изменяться до конца года по правилам согласования; будущий год может готовиться заранее.
10. Сводный график не устанавливает норматив минимальной численности. Отдельный график хранит его по году. Группы 9 и 9.1 независимы.
