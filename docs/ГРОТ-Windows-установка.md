# ГРОТ: два варианта программы — веб и Windows

## Статус
Веб-версия ГРОТ по-прежнему открывается по адресу https://bvl63.github.io/grot/ .
Добавлен проект автономной программы **ГРОТ для Windows 10/11 (64-bit)** в папке `desktop/`.
Это один набор исходных функций ГРОТ, но **два независимых локальных хранилища**.

## Windows-программа
- Приложение устанавливается из `GROT-Setup-*.exe`, запускается из меню «Пуск» или с ярлыка рабочего стола.
- Не нужен интернет, GitHub, Netlify, сервер или браузер.
- Код интерфейса и библиотеки печати вложены в установленные файлы. Для генерации PDF используются офлайн-копии библиотек.
- Данные (сотрудники, отпуска, справочники и графики) сохраняются автоматически в профиле Windows пользователя, внутри хранилища Electron/Chromium (`localStorage`). Это **не** отдельный файл JSON в папке установки.
- Папка профиля доступна через стандартную папку Windows `%APPDATA%`. По умолчанию Electron использует путь `%APPDATA%\ГРОТ` (может зависеть от версии/профиля). **Не удаляйте эту папку при переустановке**.
- Программа работает для одного локального пользователя ПК. Для одновременной совместной работы нужна будущая серверная синхронизация; этой функцией ПК-вариант пока не обладает.

## Как перенести данные из веб-ГРОТ в Windows-ГРОТ
1. Откройте веб-приложение в том браузере, где введены данные.
2. Выполните **Сервис → Резервная копия** и сохраните полученный `grot-*.json`.
3. Установите и запустите «ГРОТ» на Windows.
4. До восстановления проверьте, что в новой программе нет данных, которые нужно сохранить отдельно: восстановление **заменяет**, а не объединяет, существующую локальную базу.
5. Используйте **Сервис → Восстановить**, выберите файл `grot-*.json`, проверьте сведения и подтвердите.
6. В дальнейшем делайте резервные копии также в Windows-варианте, на другой диск или в отдельную папку.

Данные между веб и ПК **не синхронизируются автоматически**. Оба варианта могут использоваться параллельно, но изменения в одном не появляются в другом без переноса резервной копии.

## Как собрать установщик самостоятельно на ПК
Требуются Node.js 24, npm и Windows 10/11 x64:
```powershell
npm install
npm run dist:win
```
Готовый `.exe` появится в папке `release/`. Установка программы не требует Node.js.

## Сборка через GitHub Actions
В репозитории откройте **Actions → «ГРОТ — установщик Windows» → Run workflow**. После успешной сборки скачайте артефакт **GROT-Windows-Installer** из результатов запуска и распакуйте архив. Внутри будет файл `GROT-Setup-*.exe`.

> Установщик пока без цифровой подписи издателя. Windows SmartScreen может показать предупреждение. Устанавливайте только файл из собственного репозитория и проверяйте его происхождение.

## Обновление
- **Веб:** как прежде, публикация в GitHub Pages и «Сервис → Обновить».
- **ПК:** после изменений исходного кода необходимо **собрать и установить новый `.exe`**. «Сервис → Обновить» в Windows-программе только перезагружает открытый интерфейс, но не скачивает обновления. Данные в профиле пользователя остаются, если этот профиль не удалён.
- При переходе между версиями перед установкой рекомендуется сохранить резервную копию.
