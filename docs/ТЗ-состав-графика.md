# ГРОТ — Состав графика отпусков
Утверждено: 10.11.2026. Реализация: веб-версия 0.3.106.

## Принцип
Сотрудников назначают в структурное звено один раз — в справочнике «Структура предприятия».
Для отдельного графика отпусков выбираются одно или несколько структурных звеньев: подразделения, отделы, бригады. В график автоматически включаются сотрудники этих звеньев **и вложенных звеньев**. Один сотрудник учитывается один раз.

## Интерфейс
В верхней панели графика вместо «＋ Добавить сотрудников» располагается кнопка **«Состав»**.
Окно «Состав графика» содержит название графика, список структурных звеньев с кодами и числом сотрудников, итоговое количество участников и сворачиваемый блок «Исключения и отдельные сотрудники».
В исключениях пользователь ищет конкретного сотрудника по фамилии и может включить или исключить его. Общий список всех 100+ сотрудников для повторной отметки галочками **не выводится**.

## Обновление состава
- Добавление сотрудника в выбранный отдел автоматически включает его в график.
- Перевод из выбранного отдела удаляет его из текущего состава, если он не включён в порядке исключения.
- Изменение состава **не удаляет карточку сотрудника, периоды и историю отпусков**.
- Общий график включает всех сотрудников и не требует настройки состава.

## Совместимость и сохранность
Старые графики, где сохранены только `staffIds`, продолжают отображаться как прежде.
При первом открытии «Состав» для старого графика система предлагает звенья по текущим назначенным сотрудникам и подготавливает корректировки, чтобы сохранение не изменило состав неожиданно.
Переход на автоматический состав происходит **только по нажатию «Сохранить»**.
В резервной копии JSON сохраняются `structureIds`, `includeStaffIds`, `excludeStaffIds` вместе с прежним `staffIds` для совместимости.
Windows-сборки делаются отдельно, после проверки веб-версии.
